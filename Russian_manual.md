## В данном мануале будут подробно описаны все шаги, чтобы равернуть ядро сети.
---
### I. Описание имеющегося оборудования
1. Оборудование, на котором разворачивается ядро сети:
- Процессор: Intel(R) Core(TM) i7-860 
- Материнская плата: MSI P55-GD65
- ОЗУ: 8 GB
- Диск: Жесткйи диск 3.5" 650 GB
- Видокарта: NVIDIA GeForce GT 440
2. Выбранная операционная система: Lubuntu-24.04.4-desktop-amd64
- Выбор данной ОС объясняется с одной стороны иметь графичекий интерфейс, интуитивно понятный пользователю Windows (в университете в качестве рабочей ОС используется только windows 10, 7 или даже XP), а с другой стороны наличием не самого мощного компьютера.
- Также изначально необходимо подключение к интернету, котороев моем университете требует бразузера для авторизации (в целом этот пункт можно считать основной причиной выбора именно Lubuntu, а не скажем Ubuntu Server)
---
### II. Установка ОС
1. Через ventoy выберите lubuntu-24.04.4-desktop-amd64. Если вы устонавливаете через другую утилиту, перейдите к пункту 3. 
2. Выберите пункт *Boot in normal mode*
3. Затем выберите пункт *Try or Install Lubuntu*
4. Дождитесь загрузки ОС. Из-за предустановленного жестокго диска (HDD) это может занять несколько минут. Не обращайте внимания на графисечкие артефакты
5. В графе *Select language* выберите язык *русский(Россия) - Russian(Russia)*. Дождитесь смены языка системой
6. Выберите интернет соединение (у меня это изначально *WiFi Bonch Lite*). Введите пароль и авторизируйтесь в системе. Поскольку сеть требует дополнительной авторизации, то в данном случае установка будет происходить без интернета. 
7. Выберите пункт *Install Lubuntu*
8. В графе **Добро пожаловать** вы увиде сообщение, что система не подключена к интернету. Нажмите кнопку *Далее*
9. В разделе **Местоположение** укажите *__Регион:__ Европа*, *__Зона:__ Москва*. Нажмите кнопку *Далее*
10. В разделе **Клавиатура** модель клавиатуры как правило определяется автоматически (Generic 105-key PC) *Russian, По-умолчанию*. Нажмите кнопку *Далее*
11. В разделе **Customize** выберите *Normal Installation*. Нажмите кнопку *Далее*
12. В разделе **Разделы** выбираете диск установки (на данном пк он один, поэтому выбирается автоматически). После чего выбирается пункт *Стереть диск*. Если же вы ставите это на свой пк с установленной другой ОС, то выбирайте другой пункт на свое усмотрение. Выбирается пункт *Файл подкачки* и разметка *btrfs* для возможности создавать резервные копии системы и быстро к ним откатываться. Нажмите кнопку *Далее*
13. В разделе **Пользователи** задайте имена и пароль. В качестве имени рекомендуется использовать что-то короткое и одинаковое. Поставьте галочку на *Автоматический вход, без запроса пароля*. Нажмите кнопку *Далее*
14. В разделе **Сводка** проверьте все пункты и если вас все устраивает, нажмите *Установить*. После чего нажмите *Install Now*.
15. Дождитесь окончания установки ОС
16. После установки в разделе **Завершить** поставьте галочку *Перезагрузить* и нажмите *Готово*.
17. Высветиться логотип Lubuntu и надпись *Please remove the installation media, then press ENTER*. Извлеките установочную флешку и нажмите клавишу *Enter*
18. Дождитесь перезагрузки системы. После этого перейдем к настройке системы.
--- 
### III Настройка системы
После запуска и входа, необходимо провести настройки ОС.
1. Настройка языка.
- Нажмите значок пуска -> параметры -> Настройки LXQT -> Системные настройки LXQT.
- Раздел *Клавиатура и мышь* -> Раскладка клавиатуры
- Добавьте необходимые языки, а также измените клавиши смены раскладки (Я ставлю **Ctrl+Shift**)
- Выйдите из центра настроек
2. Настройка панели задач
- Наведитесь мышкой на панель задач и нажмите ПКМ
- Выберите пункт *Настроить "Панель"* (не панель задач)
- Перейдите в виджеты и нажмите на знак "плюс"
- Добавьте *Индикатор раскладки клавиатуры*. Настройте его под необходимые вам параметры.
3. Подключение к WiFi.
- Откройте Системные настройки LXQT
- Перейдите в раздел *Advanced Network Configuration*
- Нажмите ***+*** чтобы создать новое подключение
- Выберите WiFi, нажмите Create...
- Назовите ваше WiFi соединение (Connection name: Bonch Lite)
- Введите SSID системы, в моем случае это "Bonch Lite"
- Выберите также Device, в моем случае это wlx9094e403576c (WiFi USB Adapter)
- Перейдите в security и выберите тип Security и при необходимоти введите пароль
- Дополнительно сеть требует авторизации в сети. Выполняется через втроенный бразуер (Firefox)
---
### IV Обновление системы
Все дальнейшие инструкции будут выполняться в терминале. Откройте терминал сочетанием клавиш ctrl+alt+t или же иконкой в панели задач
```bash
# Обновим список актуальных пакетов системы
sudo apt update
# После получения обновленного списка, обновим систему
sudo apt upgrade
# Удалим лишние пакеты, которые были спользованы при установке
sudo apt autoremove
# +++ Теперь создадим резервную копию системы +++
